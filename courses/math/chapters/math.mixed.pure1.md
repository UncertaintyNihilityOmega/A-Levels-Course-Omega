@summary Twenty-nine short questions that mix every topic of Pure 1 (quadratics, functions, coordinate geometry, circular measure, trigonometry, series, differentiation and integration), ordered from ★ to ★★★. Each answer is a mark scheme, and each question names the chapter to revise.

:::why
In the exam you are never told which chapter a question comes from. Practice that stays inside one chapter hides the hardest skill: recognising the method. This page mixes everything on purpose, so that you have to decide, every time, what the question is really asking.
:::

:::tip How to use this page
Do the questions in order, a few at a time, on paper. ★ questions are one idea (2 to 3 marks), ★★ questions are exam standard for a typical Paper 1 question, ★★★ questions need two or more ideas together. Mark yourself with the scheme, and under each answer the **Revise** link takes you to the chapter for that topic. Keep a list of the chapters that come up more than once: they are your weak spots.
:::

:::try Warm-up ★
Q: [2 marks] (#math.p1.quadratics) ★ Solve \(x^2 - 5x - 14 = 0\).
A: Factorise: \((x - 7)(x + 2) = 0\). [M1]
So \(x = 7\) or \(x = -2\). [A1]
Q: [2 marks] (#math.p1.series) ★ Find the 10th term of the arithmetic progression \(7, 11, 15, \ldots\)
A: The first term is 7 and the common difference is 4, so \(u_{10} = 7 + 9 \times 4\). [M1]
\(u_{10} = 43\). [A1]
Q: [3 marks] (#math.p1.coord) ★ Find the equation of the straight line through \((2, 5)\) and \((6, -3)\), giving your answer in the form \(y = mx + c\).
A: The gradient is \(\dfrac{-3 - 5}{6 - 2} = -2\). [M1] [A1]
Using \((2, 5)\): \(y - 5 = -2(x - 2)\), so \(y = -2x + 9\). [A1]
Q: [3 marks] (#math.p1.diff) ★ Differentiate \(y = 3x^4 - \dfrac{2}{x^2} + 5\sqrt{x}\) with respect to \(x\).
A: Write \(y = 3x^4 - 2x^{-2} + 5x^{1/2}\). Then
\[ \frac{dy}{dx} = 12x^3 + 4x^{-3} + \tfrac52 x^{-1/2} \]
Each term is worth a mark: \(12x^3\) [B1], \(4x^{-3}\) (or \(4/x^3\)) [B1] and \(\tfrac52 x^{-1/2}\) (or \(\dfrac{5}{2\sqrt{x}}\)). [B1]
Q: [3 marks] (#math.p1.integ) ★ Find \(\displaystyle\int \Big(6x^2 - \frac{4}{x^2}\Big)\,dx\).
A: Write the integrand as \(6x^2 - 4x^{-2}\). Add one to each power and divide by the new power:
\[ 2x^3 + 4x^{-1} + c \]
\(2x^3\) [B1], \(4x^{-1}\) (or \(4/x\)) [B1] and the constant \(+c\). [B1]
Q: [2 marks] (#math.p1.circular) ★ Express \(150^\circ\) in radians, giving your answer as a multiple of \(\pi\).
A: Multiply by \(\dfrac{\pi}{180}\): \(150 \times \dfrac{\pi}{180}\). [M1]
\(150^\circ = \dfrac{5\pi}{6}\) radians. [A1]
Q: [2 marks] (#math.p1.trig) ★ The angle \(\theta\) is acute and \(\tan\theta = \dfrac34\). Find the exact values of \(\sin\theta\) and \(\cos\theta\).
A: Draw a right-angled triangle with opposite 3 and adjacent 4; the hypotenuse is \(\sqrt{9 + 16} = 5\). So \(\sin\theta = \dfrac35\) [B1] and \(\cos\theta = \dfrac45\). [B1]
Q: [3 marks] (#math.p1.quadratics) ★ Express \(x^2 + 6x + 2\) in the form \((x + p)^2 + q\) and write down the coordinates of the minimum point of the curve \(y = x^2 + 6x + 2\).
A: Half of 6 is 3: \(x^2 + 6x + 2 = (x + 3)^2 - 9 + 2\). [M1]
\(= (x + 3)^2 - 7\). [A1]
The minimum point is \((-3, -7)\). [B1]
:::

:::try Exam standard ★★
Q: [4 marks] (#math.p1.functions) ★★ The functions \(f\) and \(g\) are defined by \(f(x) = 2x + 3\) and \(g(x) = x^2\). Find \(fg(x)\) and \(gf(x)\), and hence solve the equation \(fg(x) = gf(x)\).
A: \(fg(x) = f(x^2) = 2x^2 + 3\). [B1]
\(gf(x) = g(2x + 3) = (2x + 3)^2\). [B1]
Equate: \(2x^2 + 3 = 4x^2 + 12x + 9\), which gives \(x^2 + 6x + 3 = 0\). [M1]
By the formula \(x = \dfrac{-6 \pm \sqrt{36 - 12}}{2} = -3 \pm \sqrt{6}\). [A1]
Q: [4 marks] (#math.p1.series) ★★ Find the first three terms, in ascending powers of \(x\), of the expansion of \((2 + 3x)^5\).
A: Use \((a + b)^n\) with \(a = 2\), \(b = 3x\), \(n = 5\): [M1]
\[ 2^5 + \binom51 2^4(3x) + \binom52 2^3(3x)^2 + \cdots \]
The first term is 32. [A1] The second is \(5 \times 16 \times 3x = 240x\). [A1] The third is \(10 \times 8 \times 9x^2 = 720x^2\). [A1]
Q: [3 marks] (#math.p1.trig) ★★ Solve \(\tan(x - 20^\circ) = 2\) for \(0^\circ \le x \le 360^\circ\).
A: \(\tan^{-1}2 = 63.4^\circ\), so \(x - 20^\circ = 63.4^\circ\) or \(63.4^\circ + 180^\circ = 243.4^\circ\). [M1]
\(x = 83.4^\circ\) [A1] or \(x = 263.4^\circ\). [A1]
Q: [3 marks] (#math.p1.coord) ★★ A circle has centre \((2, -1)\) and passes through the point \((5, 3)\). Find the equation of the circle.
A: The radius squared is the squared distance from the centre to \((5, 3)\): \(r^2 = (5 - 2)^2 + (3 + 1)^2 = 25\). [M1]
So \(r = 5\). [A1]
The equation is \((x - 2)^2 + (y + 1)^2 = 25\). [A1]
Q: [4 marks] (#math.p1.diff) ★★ Find the equation of the normal to the curve \(y = x^3 - 4x\) at the point where \(x = 2\), in the form \(ax + by + c = 0\) with integer coefficients.
A: When \(x = 2\), \(y = 8 - 8 = 0\), and \(\dfrac{dy}{dx} = 3x^2 - 4 = 8\). [M1] [A1]
The normal has gradient \(-\dfrac18\). [M1]
\(y - 0 = -\tfrac18(x - 2)\), so \(8y = -x + 2\), that is \(x + 8y - 2 = 0\). [A1]
Q: [4 marks] (#math.p1.integ) ★★ Find the area of the region enclosed by the curve \(y = 6x - x^2\) and the \(x\)-axis.
A: The curve meets the \(x\)-axis where \(x(6 - x) = 0\), so at \(x = 0\) and \(x = 6\). [M1]
\[ \text{Area} = \int_0^6 (6x - x^2)\,dx = \Big[3x^2 - \tfrac13 x^3\Big]_0^6 \]
[M1] [A1] \(= 108 - 72 = 36\). [A1]
Q: [3 marks] (#math.p1.quadratics) ★★ Find the set of values of \(k\) for which the equation \(kx^2 + 4x + 1 = 0\) has no real roots.
A: No real roots needs \(b^2 - 4ac < 0\): [M1]
\[ 16 - 4k < 0 \]
[A1] So \(k > 4\). [A1]
Q: [4 marks] (#math.p1.circular) ★★ A sector of a circle has radius 5 cm and angle 0.8 radians. Find the perimeter and the area of the sector.
A: The arc length is \(5 \times 0.8 = 4\) cm. [M1]
The perimeter is \(5 + 5 + 4 = 14\) cm. [A1]
The area is \(\tfrac12 \times 5^2 \times 0.8\) [M1] \(= 10\) cm². [A1]
Q: [3 marks] (#math.p1.functions) ★★ The curve \(y = x^2 - 4x\) is translated by \(\begin{pmatrix}2\\3\end{pmatrix}\) and then reflected in the \(x\)-axis. Find the equation of the resulting curve.
A: The translation replaces \(x\) by \(x - 2\) and adds 3: \(y = (x - 2)^2 - 4(x - 2) + 3\). [M1]
This simplifies to \(y = x^2 - 8x + 15\). [A1]
The reflection in the \(x\)-axis changes the sign of \(y\): \(y = -x^2 + 8x - 15\). [A1]
Q: [4 marks] (#math.p1.functions) ★★ The function \(f\) is defined by \(f(x) = \dfrac{x - 1}{x + 2}\) for \(x \ne -2\). Find an expression for \(f^{-1}(x)\) and state the value of \(x\) which is not in its domain.
A: Let \(y = \dfrac{x - 1}{x + 2}\). Then \(y(x + 2) = x - 1\), so \(xy + 2y = x - 1\). [M1]
Collect the terms in \(x\): \(x(y - 1) = -1 - 2y\), so \(x = \dfrac{1 + 2y}{1 - y}\). [M1]
\(f^{-1}(x) = \dfrac{1 + 2x}{1 - x}\). [A1]
The value \(x = 1\) is not in the domain. [B1]
Q: [4 marks] (#math.p1.series) ★★ (a) Find the sum of the first 8 terms of the geometric progression \(3, 6, 12, \ldots\) [2]

(b) Find the sum to infinity of the geometric progression \(12, 8, \tfrac{16}{3}, \ldots\) [2]
A: (a) \(S_8 = \dfrac{3(2^8 - 1)}{2 - 1}\) [M1] \(= 765\). [A1]

(b) The common ratio is \(\dfrac{8}{12} = \dfrac23\), and \(|r| < 1\), so \(S_\infty = \dfrac{12}{1 - 2/3}\) [M1] \(= 36\). [A1]
Q: [4 marks] (#math.p1.coord) ★★ The points \(A\) and \(B\) have coordinates \((1, 2)\) and \((5, 8)\). Find the equation of the perpendicular bisector of \(AB\), in the form \(ax + by + c = 0\) with integer coefficients.
A: The midpoint of \(AB\) is \((3, 5)\). [B1]
The gradient of \(AB\) is \(\dfrac{8 - 2}{5 - 1} = \dfrac32\), so the perpendicular gradient is \(-\dfrac23\). [M1]
\(y - 5 = -\tfrac23(x - 3)\), which gives \(3y - 15 = -2x + 6\). [M1]
\(2x + 3y - 21 = 0\). [A1]
Q: [3 marks] (#math.p1.trig) ★★ Prove the identity \(\tan\theta + \dfrac{1}{\tan\theta} \equiv \dfrac{1}{\sin\theta\cos\theta}\).
A: Write \(\tan\theta = \dfrac{\sin\theta}{\cos\theta}\): the left side is \(\dfrac{\sin\theta}{\cos\theta} + \dfrac{\cos\theta}{\sin\theta}\). [M1]
Over a common denominator: \(\dfrac{\sin^2\theta + \cos^2\theta}{\sin\theta\cos\theta}\). [M1]
Since \(\sin^2\theta + \cos^2\theta = 1\), this equals \(\dfrac{1}{\sin\theta\cos\theta}\). [A1]
Q: [3 marks] (#math.p1.diff) ★★ The radius \(r\) cm of a circle is increasing at a constant rate of 0.2 cm s⁻¹. Find the rate at which the area of the circle is increasing at the instant when \(r = 5\).
A: \(A = \pi r^2\), so \(\dfrac{dA}{dr} = 2\pi r\). By the chain rule \(\dfrac{dA}{dt} = \dfrac{dA}{dr}\times\dfrac{dr}{dt}\). [M1]
\(\dfrac{dA}{dt} = 2\pi \times 5 \times 0.2\) [A1] \(= 2\pi = 6.28\) cm² s⁻¹. [A1]
:::

:::try Stretch ★★★
Q: [4 marks] (#math.p1.quadratics) ★★★ Solve the equation \(2x - 7\sqrt{x} + 3 = 0\).
A: Let \(u = \sqrt{x}\), so \(x = u^2\). [M1]
\(2u^2 - 7u + 3 = 0\). [A1]
Factorise: \((2u - 1)(u - 3) = 0\), so \(u = \tfrac12\) or \(u = 3\). [M1]
Square: \(x = \tfrac14\) or \(x = 9\). [A1]
Q: [5 marks] (#math.p1.quadratics) ★★★ The line \(y = kx + 2\) is a tangent to the curve \(y = 2x^2 - 3x + 4\). Find the possible values of \(k\).
A: Equate: \(2x^2 - 3x + 4 = kx + 2\). [M1]
\[ 2x^2 - (3 + k)x + 2 = 0 \]
[A1] A tangent means the quadratic has equal roots, so \(b^2 - 4ac = 0\): [M1]
\((3 + k)^2 - 16 = 0\). [A1]
So \(3 + k = \pm 4\), which gives \(k = 1\) or \(k = -7\). [A1]
Q: [6 marks] (#math.p1.diff) ★★★ Find the coordinates of the stationary points of the curve \(y = x + \dfrac{4}{x}\) and determine their nature.
A: Write \(y = x + 4x^{-1}\). Then \(\dfrac{dy}{dx} = 1 - \dfrac{4}{x^2}\). [M1] [A1]
Setting \(\dfrac{dy}{dx} = 0\): \(x^2 = 4\), so \(x = 2\) or \(x = -2\). [M1]
The stationary points are \((2, 4)\) and \((-2, -4)\). [A1]
\(\dfrac{d^2y}{dx^2} = \dfrac{8}{x^3}\). [M1]
At \(x = 2\) it is positive, so \((2, 4)\) is a minimum; at \(x = -2\) it is negative, so \((-2, -4)\) is a maximum. [A1]
Q: [5 marks] (#math.p1.integ) ★★★ Find the exact area of the region enclosed between the curves \(y = x^2\) and \(y = 8 - x^2\).
A: Equate: \(x^2 = 8 - x^2\), so \(x^2 = 4\). [M1]
The curves meet at \(x = -2\) and \(x = 2\). [A1]
The curve \(y = 8 - x^2\) is above \(y = x^2\) between these points, so the area is
\[ \int_{-2}^{2} (8 - 2x^2)\,dx = \Big[8x - \tfrac23 x^3\Big]_{-2}^{2} \]
[M1] [A1] \(= \big(16 - \tfrac{16}{3}\big) - \big(-16 + \tfrac{16}{3}\big) = \tfrac{64}{3}\). [A1]
Q: [4 marks] (#math.p1.series) ★★★ An arithmetic progression has fifth term 17 and the sum of its first 10 terms is 185. Find the first term and the common difference.
A: Let the first term be \(a\) and the common difference \(d\). The fifth term gives \(a + 4d = 17\). [M1]
The sum gives \(\tfrac{10}{2}(2a + 9d) = 185\), so \(2a + 9d = 37\). [M1]
Subtract twice the first equation (\(2a + 8d = 34\)): \(d = 3\). [A1]
Then \(a = 17 - 12 = 5\). [A1]
Q: [6 marks] (#math.p1.circular) ★★★ A sector of a circle has radius \(r\) cm and angle \(\theta\) radians, and its perimeter is 20 cm. Find the value of \(r\) for which the area of the sector is a maximum, and find this maximum area and the corresponding value of \(\theta\).
A: The perimeter is \(2r + r\theta = 20\), so \(\theta = \dfrac{20 - 2r}{r}\). [M1]
The area is \(A = \tfrac12 r^2\theta = \tfrac12 r(20 - 2r) = 10r - r^2\). [A1]
Maximise: \(\dfrac{dA}{dr} = 10 - 2r = 0\) [M1] so \(r = 5\). [A1]
The maximum area is \(50 - 25 = 25\) cm² [A1] and \(\theta = \dfrac{20 - 10}{5} = 2\) radians. [A1]
Q: [6 marks] (#math.p1.trig) ★★★ Solve the equation \(6\cos^2x + \sin x - 5 = 0\) for \(0^\circ \le x \le 360^\circ\).
A: Use \(\cos^2x = 1 - \sin^2x\): \(6 - 6\sin^2x + \sin x - 5 = 0\). [M1]
\[ 6\sin^2x - \sin x - 1 = 0 \]
[A1] Factorise: \((3\sin x + 1)(2\sin x - 1) = 0\), so \(\sin x = -\tfrac13\) or \(\sin x = \tfrac12\). [M1]
\(\sin x = \tfrac12\) gives \(x = 30^\circ\) or \(150^\circ\). [A1]
\(\sin x = -\tfrac13\): the reference angle is \(19.5^\circ\), so \(x = 199.5^\circ\) [A1] or \(340.5^\circ\). [A1]

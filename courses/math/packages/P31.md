Check-script helper for t (standard library; put it in each check that needs it):
```python
from math import lgamma, exp, pi, log
def t_pdf(x, v): return exp(lgamma((v+1)/2) - lgamma(v/2) - 0.5*log(v*pi) - (v+1)/2*log(1 + x*x/v))
def t_cdf(x, v, n=4000):  # Simpson from 0
    h = x/n; s = t_pdf(0, v) + t_pdf(x, v) + sum((4 if i % 2 else 2)*t_pdf(i*h, v) for i in range(1, n))
    return 0.5 + s*h/3
def t_inv(p, v):
    lo, hi = 0.0, 50.0
    for _ in range(80):
        mid = (lo+hi)/2
        lo, hi = (mid, hi) if t_cdf(mid, v) < p else (lo, mid)
    return lo
```

## math.fm.crv · Continuous random variables (5–6 hours)
Outcomes (FACTS.md 4.1):
- 4.1a use a probability density function which may be defined piecewise;
- 4.1b use the general result E(g(X)) = ∫ g(x) f(x) dx, where f(x) is the PDF of X and g(X) is a function of X;
- 4.1c understand and use the relationship between the PDF and the cumulative distribution function (CDF), and use
  either to evaluate probabilities or percentiles;
- 4.1d use CDFs of related variables in simple cases (given the CDF of X, find the CDF of a related variable Y, and
  hence its PDF, e.g. Y = X³).
Cover: recap of 9709 PDFs (link); piecewise PDFs (sketch, total area 1, continuity not required), finding constants
(June 2025 FS Q2 shape: a piecewise PDF from a diagram, three constants); F(x) = ∫ f, defined on every interval
including F = 0 and F = 1 outside (the classic omission); f = F′; median, quartiles, percentiles from F; E(g(X)),
E(X²), E(1/X), Var; CDF method for Y = g(X) (monotonic g: G(y) = P(Y ≤ y) = P(X ≤ g⁻¹(y)) = F(g⁻¹(y)); the range of
Y; then g(y) = G′(y)); mode.
Pitfalls: CDF not given for all real values; forgetting to differentiate to get the PDF; wrong limits for Y.
Figures: `:::plot` of a piecewise PDF (use the domain trick) and its CDF.

## math.fm.inference · The t-distribution: one-sample tests and intervals (5–6 hours)
Outcomes (FACTS.md 4.2a, 4.2d):
- 4.2a formulate hypotheses and apply a hypothesis test concerning the population mean using a small sample drawn
  from a normal population of unknown variance, using a t-test;
- 4.2d determine a confidence interval for a population mean, based on a small sample from a normal population with
  unknown variance, using a t-distribution.
Cover: why t (s estimates σ, extra uncertainty, heavier tails; tends to N(0, 1) as ν → ∞), ν = n − 1, reading the MF19
t table (p is P(T ≤ t); one- and two-tailed), test statistic t = (x̄ − μ₀)/(s/√n) with s² unbiased (link 9709),
assumptions (normal population, random sample), full test layout; confidence interval x̄ ± t·s/√n; interpreting an
interval and using it to test (inside or outside); raw data and summary data (Σx, Σx²).
Widget: embed **fm-tdist** (compare t and normal tails, then the critical region).
Pitfalls: n instead of n − 1; biased variance; one-tailed table value for a two-tailed test.

## math.fm.twosample · Comparing two means (6–8 hours)
Outcomes (FACTS.md 4.2b, 4.2c, 4.2e):
- 4.2b calculate a pooled estimate of a population variance from two samples (raw or summarised data);
- 4.2c formulate hypotheses concerning the difference of population means, and apply, as appropriate, a 2-sample
  t-test, a paired sample t-test, or a test using a normal distribution (the ability to select the test appropriate
  to the circumstances is expected);
- 4.2e determine a confidence interval for a difference of population means, using a t-distribution or a normal
  distribution, as appropriate.
Cover: a decision `:::steps` or table (paired? → paired t; independent, small, normal, equal variances → pooled
2-sample t with ν = n₁ + n₂ − 2; large samples → normal test with s₁²/n₁ + s₂²/n₂, no equal-variance assumption, CLT);
pooled variance (MF19 gives it: say so); paired t on differences; normal test for large samples (June 2025 FS Q1
shape [7]); known population variances → normal test; testing a non-zero difference (μ₁ − μ₂ = k); confidence
intervals for μ₁ − μ₂ (June 2025 FS Q4 shape: pooled t interval [6], then use it to decide a test at 5% [1]); stating
assumptions for each test.
Pitfalls: pooling when samples are large or variances not assumed equal; treating paired data as independent;
degrees of freedom.

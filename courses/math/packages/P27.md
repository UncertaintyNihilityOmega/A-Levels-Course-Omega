## math.fm.de · First order differential equations (5–6 hours)
Outcomes (FACTS.md 2.6a, 2.6e for first order, 2.6f):
- 2.6a find an integrating factor for a first order linear differential equation, and use an integrating factor to
  find the general solution (e.g. dy/dx − 2y = x, x dy/dx − 4y = x, coth x dy/dx + y = cosh x);
- 2.6e use a given substitution to reduce a differential equation to a first order linear equation or to a first
  order equation with separable variables (e.g. y = ux to reduce dy/dx = (x + y)/(x − y)-type equations);
- 2.6f use initial conditions to find a particular solution, and interpret a solution in terms of a problem modelled
  by a differential equation.
Cover: standard form dy/dx + P(x)y = Q(x) (divide through first: the classic slip); IF e^{∫P dx}, simplifying
e^{ln …}; d/dx(IF·y) = IF·Q; integrate (by parts often); general and particular solutions; "exact" equations where
one side is already a product derivative; substitutions given in the question (y = ux homogeneous type, z = y⁻¹ or
similar Bernoulli-type when given); modelling contexts (mixing tank, cooling with a varying surrounding temperature,
current in a circuit, population with harvesting); long-term behaviour as x → ∞.
Pitfalls: not dividing by the coefficient of dy/dx; IF with a modulus (choose the sign region); constant added after
dividing.

## math.fm.de2 · Second order differential equations (7–9 hours)
Outcomes (FACTS.md 2.6b–f):
- 2.6b recall the meaning of the terms "complementary function" and "particular integral" in the context of linear
  differential equations, and recall that the general solution is the sum of the complementary function and a
  particular integral;
- 2.6c find the complementary function for a first or second order linear differential equation with constant
  coefficients (auxiliary equation with distinct real roots, a repeated real root or conjugate complex roots);
- 2.6d recall the form of, and find, a particular integral for a first or second order linear differential equation
  in the cases where a polynomial or a e^(bx) or a cos px + b sin px is a suitable form, and in other simple cases find
  the appropriate coefficient(s) given a suitable form of particular integral (e.g. evaluate k given that kx cos 2x is a
  particular integral of d²y/dx² + 4y = sin 2x);
- 2.6e use a given substitution to reduce a differential equation to a second order linear equation with constant
  coefficients (e.g. x = eᵗ for ax²y″ + bxy′ + cy = …);
- 2.6f use initial conditions to find a particular solution, and interpret a solution in terms of a modelled problem.
Cover: why e^(mx) (try it: the auxiliary equation); the three CF cases with a `:::key` table (A e^(m₁x) + B e^(m₂x);
(A + Bx)e^(mx); e^(px)(A cos qx + B sin qx)); first order constant-coefficient equations by the same CF + PI route;
PI table (polynomial of the same degree; a e^(bx), with x e^(bx) or x² e^(bx) when b is a root, given in the
question when needed; a cos px + b sin px, both terms always); finding the PI by substitution and comparing
coefficients; GS = CF + PI; initial conditions for y and dy/dx (June 2025 FP2 Q5 shape [10]); oscillation and
damping (real context: a damped spring; link [Hooke's law and elastic energy](#math.fm.elastic) only as a forward
mention); substitution x = eᵗ with the chain rule written out (derive x dy/dx = dy/dt and
x² d²y/dx² = d²y/dt² − dy/dt as an `:::eg` with marks); the long-term behaviour (transient CF dies away when the
roots have negative real part).
Pitfalls: PI with only a cos term; the PI clashing with the CF; applying the initial conditions to the CF before
adding the PI.
Widget: embed **fm-de** in the CF section.

### Widget spec: fm-de (widgets/fm-de.js)
- `data-a="1" data-b="2" data-c="5"` for a y″ + b y′ + c y = 0, `data-y0="1" data-v0="0"` initial values.
- Shows the auxiliary equation am² + bm + c = 0, its roots (real distinct / repeated / complex p ± qi, as text), the
  CF form, the particular solution through (0, y₀) with gradient v₀, and its graph for 0 ≤ x ≤ 10 (W.axes; y-range
  follows the solution, capped sensibly for growing solutions with a note "grows without bound").
- Sliders for b and c (a fixed at 1 unless given), number boxes for y₀ and v₀; readout names the case ("roots
  −1 ± 2i: oscillations that die away") and the solution formula with 3 s.f. constants.
- Exact formulas for each case (no numerical ODE solver). Node-test each case against a fine RK4 integration.

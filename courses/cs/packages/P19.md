## cs.exam.p2 · Paper 2 guide: Problem-solving and Programming (`@paper CAIE 9618 Paper 2` · `@time 2–3 hours`)
- The paper from FACTS.md: 2 h, 75 marks, sections 9–12, pseudocode answers, the insert (list exactly what it
  contained in May/June 2025: string, numeric, date, file functions and operators), no calculator; the May/June 2025
  paper had 7 questions built on scenarios, ending with a long multi-module question.
- How to write pseudocode for marks: the guide's conventions (COURSE.md list), declare variables, use the insert's
  functions exactly, indentation, meaningful identifiers, comments for non-obvious steps, efficient loops; mark points
  are awarded per feature, so a partly correct algorithm still scores.
- Question types: identifier tables; flowchart ↔ pseudocode; trace tables (one row per change); stacks/queues with
  pointers; writing functions/procedures from a module description; text-file processing; structure charts; testing
  and test data; amending given code.
- Model answers: three `:::eg` (a trace table, a 6-mark function, a file-processing procedure) with mark points.
- Common slips: Python syntax in pseudocode (`for i in range`, `==`, `print`), missing `ENDIF`/`NEXT`, CALL on a
  function, string positions off by one, WRITE instead of APPEND, not closing files, not returning a value.

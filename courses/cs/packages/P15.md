## cs.ai · Graphs and pathfinding: Dijkstra and A* (`@time 5–7 hours`)
Outcomes (FACTS.md 18.1, first part): how graphs can be used to aid AI; purpose and structure of a graph; use A* and
Dijkstra's algorithms to perform searches on a graph (candidates will not be required to write algorithms to set up,
access or search graphs).
Cover: graph terms (vertex/node, edge, weighted, directed/undirected, path, cost, neighbour); graphs modelling AI
problems (route finding on maps, game levels as grids, networks of states for puzzles, robot navigation); representing
a graph (diagram, adjacency matrix and list: brief, the graph ADT is in cs.adts); Dijkstra's algorithm as Cambridge
expects it applied by hand: a table with each node's current shortest distance and previous node, the visited set,
choosing the unvisited node with the smallest distance, relaxing neighbours, until the target is visited; then trace
the path back with the "previous" column; A*: f = g + h, the heuristic (given in the question, e.g. straight-line
distance or Manhattan distance on a grid), the open and closed lists, expanding the node with the lowest f, why A*
explores fewer nodes than Dijkstra when the heuristic is good, and that it still finds the shortest path when the
heuristic never overestimates (say "admissible" once, as a stretch fact); worked example on the same graph with both
algorithms to compare the number of nodes expanded; grid example with Manhattan heuristic.
- `:::def`: graph, vertex, edge, weighted graph, directed graph, path, Dijkstra's algorithm, A* algorithm, heuristic,
  g-cost, h-cost, f-cost.
- Pitfalls: stopping Dijkstra when the target is first reached as a neighbour (it must be selected as the smallest);
  adding h to the g of the next node twice; forgetting to update a node's previous node when a shorter route appears.
- Exam-style: complete a Dijkstra table on a 6-node graph and state the shortest path and cost (6); apply A* with
  given heuristics and list the order nodes are expanded (6); explain why A* may be more efficient than Dijkstra (2).
- Checks: Python implementations of both algorithms (with the tie-breaking rule the chapter states: alphabetical) assert
  every table entry in the chapter.
- Figures: hand SVG of the weighted graph used in the examples (nodes as circles with letters, weights as halo labels
  on edges; coordinates checked).
- Widget **cs-path** after the A* section.
- Links: SME `18-artificial-intelligence-ai-/artificial-intelligence-ai/exam-questions/`, VisuAlgo sssp, 101 Computing
  Dijkstra and A*.

## cs.ml · Machine learning and neural networks (`@time 4–6 hours`)
Outcomes (FACTS.md 18.1, second part): how artificial neural networks have helped with machine learning; deep
learning, machine learning and reinforcement learning, and the reasons for using them; machine-learning categories
including supervised and unsupervised learning; back propagation of errors and regression methods in machine learning.
Cover: AI vs machine learning vs deep learning (nested ideas); machine learning (the system improves at a task from
data rather than being explicitly programmed); supervised (labelled data: classification and regression; e.g. spam
filter), unsupervised (unlabelled: clustering, finding patterns; e.g. customer groups), reinforcement learning (agent,
environment, actions, rewards, policy; trial and error: games, robotics); artificial neural networks (input layer,
hidden layers, output layer, nodes, weighted connections, a weighted sum and an activation function; one tiny network
calculated by hand with small whole-number weights); training: forward pass, error at the output, back propagation of
errors adjusts the weights layer by layer from the output back to reduce the error (gradient descent described in
words), repeated over many examples (epochs); deep learning (many hidden layers, learns features itself; needs lots of
data and computing power; image and speech recognition); regression (fitting a line or curve to predict a continuous
value; linear regression by least squares with a small data set computed exactly in the checks; why it is a
supervised method); reasons for choosing each method; limitations (data quality, bias, explainability).
- `:::def`: machine learning, deep learning, artificial neural network, node (neuron), weight, activation function,
  hidden layer, supervised learning, unsupervised learning, reinforcement learning, back propagation, regression,
  training data.
- Pitfalls: "back propagation sends data backwards through the network" (it propagates the error to adjust weights);
  reinforcement learning is not supervised (no labelled answers, only rewards); regression predicts numbers,
  classification predicts categories.
- Exam-style: describe how an ANN is trained using back propagation (5); identify the type of learning for scenarios
  (3); explain why deep learning suits image recognition (2); compute a single neuron's output (2).
- Python: a single neuron forward pass and one weight-update step with fixed numbers (no libraries; checks assert);
  least-squares line for five points with `fractions.Fraction`.
- Figure: hand SVG of a 3-4-2 network with labelled layers (fig).
- Links: 3Blue1Brown video and lesson series, TensorFlow Playground, SME AI exam questions, Computerphile.

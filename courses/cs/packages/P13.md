## cs.boolean · Boolean algebra, Karnaugh maps, adders and flip-flops (`@time 6–8 hours`)
Outcomes (FACTS.md 15.2): truth tables for logic circuits including half adders and full adders (gates may have more
than two inputs); SR and JK flip-flops: draw the circuit and derive the truth table; flip-flops as data storage
elements; Boolean algebra and De Morgan's laws; simplify a circuit/expression with Boolean algebra; Karnaugh maps:
benefits and solving problems.
Cover: notation: this chapter introduces \(A \cdot B\) (AND), \(A + B\) (OR) and NOT written as `NOT A` or \(A'\)
— choose one and keep it (COURSE.md: never `\overline`); show the word form beside it at first; laws with a truth-table
check each (identity, null, idempotent, complement, double complement, commutative, associative, distributive,
absorption, De Morgan's: NOT(A AND B) = NOT A OR NOT B, NOT(A OR B) = NOT A AND NOT B); simplification worked line by
line with the law named on each line (`:::proof`-style lines are not needed: use `aligned` maths with the law in
`\text{}`); sum of products from a truth table, then simplify; half adder (S = A XOR B, C = A AND B) and full adder
(two half adders and an OR) with truth tables and a circuit; chaining full adders for multi-bit addition; SR
flip-flop from two cross-coupled NOR gates (or NAND gates: say which; the truth table differs: state both clearly
or teach the NOR version only), states set/reset/no change/invalid; JK flip-flop (clocked, J = K = 1 toggles, removes
the invalid state); flip-flops store one bit: registers and SRAM are built from them; Karnaugh maps for 2, 3 and 4
variables with Gray code order (00, 01, 11, 10), groups of 1, 2, 4, 8 rectangles, wrap-around, overlapping allowed,
largest groups, each group gives one product term; benefits (fewer gates, cheaper, faster, less power; easier than
algebra for up to four variables).
- `:::def`: Boolean algebra, De Morgan's laws, sum of products, half adder, full adder, flip-flop, SR flip-flop, JK
  flip-flop, Karnaugh map, Gray code.
- Pitfalls: K-map axes not in Gray code; groups of 3 or 6; missing the wrap-around; De Morgan's applied without
  flipping AND/OR; S and R both 1 in an SR (NOR) flip-flop is invalid.
- Exam-style: simplify an expression using the laws, naming each (4); complete a K-map from a truth table and write
  the simplified expression (4); complete the truth table of a full adder (4); explain the role of the clock in a JK
  flip-flop (2).
- Checks: every simplification is verified by comparing truth tables in Python (all input combinations).
- Figures: hand SVGs of the half adder, the full adder and the SR flip-flop (coordinates checked); K-maps as
  Markdown tables with the Gray-code headers.
- Widget **cs-kmap** in the K-map section; `cs-logic` (P4) may be reused for checking expressions with four inputs.
- Links: SME `15-hardware-and-virtual-machines-/boolean-algebra-and-logic-circuits/exam-questions/`, Logicly,
  Nand2Tetris.

## cs.os · Operating systems: processes, scheduling and memory (`@time 5–7 hours`)
Outcomes (FACTS.md 16.1): how an OS maximises the use of resources; how the user interface hides the complexities of
the hardware; process management: multi-tasking, a process, the states running, ready and blocked; the need for
scheduling and the function and benefits of round robin, shortest job first, first come first served, shortest
remaining time; the kernel as interrupt handler and low-level scheduling; virtual memory, paging and segmentation,
their difference, page replacement, disk thrashing.
Cover: resources (CPU time, memory, I/O devices) and keeping the CPU busy while processes wait for I/O; UI layers
(GUI/CLI → system calls → drivers → hardware); process vs program; the state diagram (new → ready → running →
blocked → ready …, terminated) with the event on each transition; multi-tasking by time-slicing; schedulers (long-term
and low-level, in general terms); each scheduling algorithm with a worked Gantt chart, waiting time and turnaround
time for 4 processes with given arrival and burst times, and its benefits/drawbacks (FCFS simple, convoy effect; SJF
minimises average waiting, needs burst estimates, starvation; SRT pre-emptive SJF; RR fair, quantum choice); interrupts
and the kernel (timer interrupt ends a time slice; I/O completion moves a process from blocked to ready; ISR
dispatch); paging (fixed-size pages and frames, page table, logical → physical address), segmentation (variable-size
logical segments), the difference; virtual memory (secondary storage used as an extension of RAM; pages swapped in on
demand; page fault); page replacement (FIFO, least recently used, in general terms); disk thrashing (more time
swapping pages than executing: causes, effects, remedies).
- `:::def`: process, multi-tasking, scheduling, each scheduling algorithm, pre-emptive, kernel, interrupt handler,
  paging, page, frame, page table, segmentation, virtual memory, page fault, disk thrashing.
- Pitfalls: blocked → running directly (it must go to ready first); SJF vs SRT (pre-emption); a page is fixed size, a
  segment is not; thrashing is not "the disk is full".
- Exam-style: complete a process-state diagram with transitions (4); draw a Gantt chart and compute average waiting
  time for RR with quantum 2 (5); explain how virtual memory allows larger programs and how thrashing occurs (5).
- Checks: a Python scheduler simulation recomputes every Gantt chart and average in the chapter.
- Widget **cs-sched** with the scheduling section.
- Links: SME `16-system-software-/purposes-of-an-operating-system-os/exam-questions/`, Computerphile.

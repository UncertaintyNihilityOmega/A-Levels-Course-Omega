## Notes for this course
- Papers (verify in the syllabus): 1 theory fundamentals and 2 fundamental problem-solving and programming (AS);
  3 advanced theory and 4 practical (A Level, on a computer in Python, Java or Visual Basic). One mock per paper; the
  Paper 4 mock gives tasks to code with expected outputs and a mark scheme.
- Code: **Cambridge pseudocode** (the syllabus's pseudocode guide is the authority: verify keywords such as
  `DECLARE`, `ENDIF`, `←`) and **Python 3** for the practical paper. Code blocks in fenced ```python /
  ```text blocks. Every Python example must run: `checks/<id>.py` runs it and asserts the output shown.
- Maths links (grep kit/LINKS.md): logs and powers of 2, graph algorithms, recursion and induction.
- Widget ideas: `cs-binary` (bases, two's complement, BCD, floating point), `cs-logic` (build a circuit, truth table),
  `cs-sort` (step through bubble/insertion sort, binary search), `cs-path` (Dijkstra and A* on a small graph),
  `cs-stack` (stack, queue, linked list operations), `cs-fde` (fetch–decode–execute with registers).
